
\section{模型检验}

模型检验就是对所建立的模型就其可行性、准确性和实用性等进行检验。一般根据问题的要求和模型特点,主要包括误差分析、灵敏度分析、稳健性检验三种~\cite{ref3}。

\subsection{灵敏度分析}

% 适用:优化 / 评价 / 多参数模型

\subsection{稳健性检验}

% 适用:全题型(通用)
% 替换多种算法、调整参数区间重复求解,验证结果趋势一致、误差可控。

为验证模型结论的可靠性,本文采用以下稳健性检验策略:

\begin{itemize}[itemindent=2em]
  \item \textbf{替换对比算法:}采用【对比方法 1】、【对比方法 2】替换【主方法】重新求解,核心结论趋势一致,误差可控。
  \item \textbf{调整参数区间:}在【参数区间 1】、【参数区间 2】范围内重复求解,结果波动在可接受范围。
  \item \textbf{更换数据子集:}在【数据划分方式】下重新训练/求解,模型表现稳定。
\end{itemize}

综合上述检验,本文所建立的主要模型在误差分析、灵敏度分析和稳健性检验中均表现出较好的稳定性,验证了模型结论无偶然性,普适性极强。
