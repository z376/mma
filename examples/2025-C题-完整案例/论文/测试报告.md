## 3. Stage 1 关键发现

### 3.1 问题识别

| # | 题目问题 | 类型 | 关键变量 |
|---|---------|------|---------|
| 1 | Y 浓度 与 孕周/BMI 关系模型 + 显著性 | **回归** | 孕周、BMI、年龄、身高、体重、IVF → Y 浓度 |
| 2 | BMI 分组 + 最佳 NIPT 时点 + 误差 | **聚类 + 优化** | BMI 分组,组内时点 |

- **2 sheet:** 男胎 1082 条 / 女胎 605 条
- **31 列:** 序号、孕妇代码、年龄、身高、体重、末次月经、IVF妊娠、检测日期、检测抽血次数、检测孕周、孕妇BMI、原始读段数、比对比例、重复比例、唯一比对读段数、GC含量、13/18/21号Z值、X/Y Z值、Y/X染色体浓度、13/18/21号GC含量、被过滤比例、染色体非整倍体、怀孕次数、生产次数、胎儿是否健康

- **关键判据:** 男胎 Y 浓度 ≥ 4% 视为达标(题目硬约束)
- **关键风险:** 早期(<12 周)低 / 中期(13-27 周)高 / 晚期(>28 周)极高(题目给定性)

## 6. 已知问题(不阻塞 Stage 1-2)

### 6.1 OTF 字体位置错位(P2,Stage 6 阻塞)

- **现象:** `workspace/论文/SourceHanSerifCN-*.otf` 在根目录,不是 `fonts/` 子目录
- **原因:** mma skill 论文/ 复制时 `Copy-Item -Recurse` 把 fonts/ 子目录里的文件展开到根
- **修复:** 把 2 个 OTF 移到 `workspace/论文/fonts/` 目录
- **影响:** Stage 6 编译会找不到字体失败;Stage 3-5 不影响

### 6.2 workspace 论文/ 残留临时产物(P3,影响 build.ps1 编译)

- **现象:** `论文.aux/.log/.out/.pdf`、`AI工具使用详情.*` 等几个文件
- **原因:** 之前在 mma 仓库测试 build.ps1 留下的,被 .gitignore 忽略但实际文件还在
- **影响:** 不影响 Stage 3-5 写作,但 Stage 6 编译时如果 build.ps1 找到这些文件可能报错
- **修复:** 删 `论文.aux` / `论文.log` / `论文.out` / `论文.pdf` / `AI工具使用详情.aux/log/out/pdf/tex` (注意:AI详情 .tex 保留 template 版本,不要用填充版)

### 6.3 check_input.py emoji 编码(已修复,推 b9baa5c)

- **现象:** Windows GBK stdout 不能编码 emoji 🔍 📂
- **修复:** 加 `sys.stdout.reconfigure(encoding='utf-8')`
- **状态:** ✅ 已推到 GitHub

### 6.4 auto_verify.py subprocess reader thread(已知,未修)

- **现象:** Python 3.12 + Windows GBK 下 subprocess 读 xelatex 输出时,reader 线程报 UnicodeDecodeError
- **影响:** 在 mma skill 仓库根目录跑 auto_verify.py 会崩(因为没有题目/数据/工作区)
- **绕过:** 在题目工作区跑 auto_verify.py 不触发(不调 xelatex)
- **修复:** 加 `os.environ["PYTHONIOENCODING"] = "utf-8"` 或在 Python 启动前设
