# 论文写作硬规则(2026 国赛规范,违反即扣分)

> **单一来源**:所有 mma 文档引用硬规则,都从这里取。其他文档用一句话指向即可。

---

## 7 条硬规则(违反即扣分)

| # | 规则 | 例外 |
|---|------|------|
| 1 | 正文无分点符号(①②③、●○、1.2.3.) | 模型假设/评价的 itemize |
| 2 | 正文不加粗 `\textbf{}` | 摘要"对于问题X"、问题重述"问题N:"、假设/优缺点头部 |
| 3 | 全文无多余 `\newpage` | 仅 9.参考文献.tex 前 和 10.附录.tex 前可用 |
| 4 | 图上无标题(`set_title()`) | 标题由 `\caption{}` 承担 |
| 5 | 表格格子文字一行显示 | 不换行 |
| 6 | 摘要 ≤ 1 页、不含公式 | 虎头/猪肚/豹尾三段式(见下) |
| 7 | 无目录 `\tableofcontents` | 2026 规范第四条:论文不要目录 |

## 摘要三段式(2026 官方模板,虎头/猪肚/豹尾)

| 段 | 别名 | 内容 | 典型长度 |
|----|------|------|----------|
| 第一段 | 虎头(背景+问题) | 题目背景、现存问题、研究意义;明确本文要解决的所有问题 | 1 段,2-3 句 |
| 第二段 | 猪肚(方法+结果) | 按问题顺序:建模思路 → 数据处理 → 模型方法 → 求解过程 → 量化结果 | 1 段,4-6 句 |
| 第三段 | 豹尾(创新+价值) | 模型优势/创新点 + 精度/稳定性/鲁棒性,或应用价值/推广意义 | 1 段,2-3 句 |

模板:`论文/0.摘要.tex` 已经按三段式留好占位符(虎头/猪肚/豹尾三个 `% ==========` 注释段),直接填即可。

## 参考文献中 AI 工具引用格式(2026 官方模板第 8 条)

AI 工具必须列在参考文献中,格式:

```
[编号] 工具名称, 版本/型号, 开发机构/公司, 使用日期.
```

示例:

```
[11] DeepSeek, DeepSeek-R1-0528, 深度求索(DeepSeek), 2025-09-05.
[12] ChatGPT, GPT-4o, OpenAI, 2025-09-05.
```

位置:和其他文献混排,通常放最后。`论文/9.参考文献.tex` 已留 `\bibitem{aideepseek}` 占位符。

正文相应位置也需标注(右上角 `\cite{aideepseek}`),模板未给具体格式,建议脚注式或文末集中说明。

## 硬性数字(用于自检和评估)

| 项 | 约束 | 备注 |
|----|------|------|
| 摘要字数 | ≤ 900 字(约 1 页) | 开头 ≤30 + 逐问 + 结尾 ≤20 |
| 问题数 | 4 个(国赛标准) | 视赛题而定 |
| 每问公式数 | ≥ 6 个 | 公式间用中文过渡句串联 |
| 每问图片数 | ≥ 4 张 | 图片/ 目录,先算后画 |
| 参考文献数 | 8-15 条 | GB/T 7714-2015,优先中文 |
| 表格格式 | 全部 longtable + `>{\centering\arraybackslash}p{}` | 不用 tabular/tabularx |
| 图宽 | `0.8\textwidth` | A4 单栏 |
| 表宽 | `\textwidth` | — |
| 行距 | 1.5 倍 | format.cls 已设 |
| 正文页数 | ≤ 30 页 | 不含附录 |
| 灵敏度分析 | ±10% ±20% 扰动 | 核心参数 |
| 5 折 CV | 5-fold cross-validation | 默认评估方式 |
| AI 工具标注 | 每段代码后注明 | "该部分代码使用 AI 工具:..." |
