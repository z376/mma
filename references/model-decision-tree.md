## 总入口:看题问什么

```
题目问什么?
├─ "最优/最大/最小/调度/分配/规划"    → 优化类
├─ "评价/排序/比较/打分/选优"         → 评价类
├─ "预测/估计/趋势/未来"             → 预测类
├─ "分类/识别/判别/分群"             → 分类类
├─ "为什么/机理/动态/演化"           → 机理类
└─ 不清楚/混合                       → 走混合决策(见末尾)
```

## 优化类

**题型关键词**:调度、分配、路径、规划、配比、最小成本、最大收益

### 决策树

```
决策变量 + 约束 + 目标 都明确?
├─ 是,规模小(< 100 变量)
│   └─ 推荐:线性/整数规划(pulp/scipy.optimize.linprog)
│       备选:动态规划(规模大但可分阶段)
└─ 否,或规模大(> 1000 变量)
    ├─ 有清晰适应度函数
    │   └─ 推荐:遗传算法(GA) / 粒子群(PSO)
    │       备选:模拟退火(SA) / 蚁群(ACO)
    └─ 是组合优化(TSP/VRP 类)
        └─ 推荐:蚁群(ACO) / GA
```

### 候选池(选 2 个搭)

| 方法 | 库 | 适用规模 | 优点 | 缺点 |
|------|-----|---------|------|------|
| 线性/整数规划 | `pulp` / `scipy.optimize` | 小-中 | 精确解、稳定 | 需线性、整数变量难 |
| 遗传算法(GA) | `geatpy` / `deap` | 中-大 | 全局搜索、不要求线性 | 慢、参数敏感 |
| 粒子群(PSO) | `pyswarm` | 中-大 | 收敛快、实现简单 | 易早熟 |
| 模拟退火(SA) | 自实现 | 中 | 跳出局部最优 | 调温曲线关键 |
| 蚁群(ACO) | `aco-pants` | 组合优化 | 路径类问题强 | 慢 |

### 硬性要求

- 优化题:≥1 个精确算法 + ≥1 个启发式(否则扣分)

## 评价类

**题型关键词**:排序、打分、选优、综合评价、指标体系

### 决策树

```
权重怎么定?
├─ 主观(专家打分)
│   └─ AHP 层次分析 / 模糊综合评价
├─ 客观(从数据算)
│   └─ 熵权法 / CRITIC / 灰色关联
└─ 都要
    └─ 主观 + 客观组合(更稳)

数据怎么聚合?
├─ 距离/相似度
│   └─ TOPSIS / 灰色关联
├─ 综合得分
│   └─ 加权求和
└─ 模糊
    └─ 模糊综合评价
```

### 候选池(选 2-3 个搭)

| 方法 | 库 | 适用 | 优点 | 缺点 |
|------|-----|------|------|------|
| AHP 层次分析 | 自实现 | 主观权重 | 直观、易解释 | 一致性检验烦 |
| 熵权法 | 自实现 | 客观权重 | 客观、不需专家 | 对极端值敏感 |
| CRITIC | 自实现 | 客观权重 | 兼顾变异+冲突 | 实现稍复杂 |
| TOPSIS | 自实现 | 排序 | 简单稳定 | 权重需先定 |
| 灰色关联 | 自实现 | 小样本 | 不要求大样本 | 理论门槛 |
| 模糊综合 | 自实现 | 模糊指标 | 处理语言变量 | 隶属函数主观 |

### 硬性要求

- 评价题:≥1 个主观赋权(AHP)+ ≥1 个客观赋权(熵权/CRITIC)

## 预测类

**题型关键词**:预测、趋势、未来值、估计

### 决策树

```
时间维度?
├─ 有时间序列
│   ├─ 数据平稳+线性
│   │   └─ ARIMA / 指数平滑
│   ├─ 非线性、有周期
│   │   └─ Prophet / SARIMA / STL
│   └─ 多变量、长依赖
│       └─ LSTM / Transformer
└─ 非时间(横截面回归)
    ├─ 特征数 < 样本数
    │   └─ 多元回归 / Lasso
    └─ 特征数 ≥ 样本数
        └─ 随机森林 / XGBoost
```

### 候选池(选 2 个搭)

| 方法 | 库 | 适用 | 优点 | 缺点 |
|------|-----|------|------|------|
| ARIMA | `statsmodels` | 平稳单变量 | 经典、可解释 | 需平稳、难调 |
| Prophet | `prophet` | 强季节性 | 自动、鲁棒 | 黑盒 |
| 多元回归 | `sklearn.linear_model` | 线性关系 | 简单、可解释 | 难捕捉非线性 |
| 随机森林 | `sklearn.ensemble` | 非线性 | 鲁棒、不用调太多 | 解释性差 |
| XGBoost / LightGBM | `xgboost` / `lightgbm` | 表格数据 | 强 baseline | 调参多 |
| LSTM | `pytorch` | 长序列 | 强拟合 | 慢、需数据多 |
| GM(1,1) 灰色预测 | 自实现 | 小样本 | 不需大样本 | 只适合指数增长 |

### 硬性要求

- 有数据题:≥1 个机器学习/统计 + ≥1 个传统机理

## 分类类

**题型关键词**:分类、识别、判别、分群

### 决策树

```
有标签?
├─ 是
│   ├─ 二分类
│   │   └─ 逻辑回归 / SVM / 随机森林
│   └─ 多分类
│       └─ XGBoost / 随机森林 / SVM + softmax
└─ 无(聚类)
    └─ K-Means / DBSCAN / 层次聚类
```

### 候选池

| 方法 | 库 | 适用 |
|------|-----|------|
| 逻辑回归 | `sklearn.linear_model` | 二分类、线性可分 |
| SVM | `sklearn.svm` | 小样本、高维 |
| 随机森林 | `sklearn.ensemble` | 表格数据、baseline |
| XGBoost | `xgboost` | 表格数据、效果强 |
| KNN | `sklearn.neighbors` | 小样本、局部敏感 |
| 朴素贝叶斯 | `sklearn.naive_bayes` | 文本、独立特征 |
| CNN | `pytorch` | 图像 |
| K-Means | `sklearn.cluster` | 聚类 |

## 机理类

**题型关键词**:为什么、演化、动力学、扩散、传播

### 决策树

```
物理过程?
├─ 连续变化(浓度/温度/种群)
│   └─ 微分方程(ODE/PDE) + 数值解(scipy.integrate.solve_ivp)
├─ 离散演化(格子/网络)
│   └─ 元胞自动机 / Agent-Based / 网络传播
└─ 物理定律清楚
    └─ 动力学方程 + 参数估计
```

### 候选池

| 方法 | 库 | 适用 |
|------|-----|------|
| ODE 数值解 | `scipy.integrate` | 种群、化学反应 |
| 元胞自动机 | 自实现(用 numpy 向量化) | 交通流、传染病 |
| Agent-Based | `mesa` / 自实现 | 复杂系统 |
| 动力学建模 | `sympy` + scipy | 物理系统 |

## 混合问题

很多题是混合的,常见套路:

| 套路 | 含义 | 例子 |
|------|------|------|
| 预测+优化 | 先预测未来,再优化调度 | 销量预测 + 库存优化 |
| 评价+预测 | 用历史数据评价,再预测未来排名 | 信用评分 |
| 机理+数据 | 机理打底,数据调参 | 传染病 SEIR + 真实数据 |
| 优化+评价 | 多目标优化后用 TOPSIS 选最优解 | 多方案排序 |

混合题每个子问题分别走决策树,然后串起来。

---

## 决策时的常见错误

1. ❌ 题里说"预测"就只跑 ARIMA → ✅ 至少 1 个统计 + 1 个 ML
2. ❌ 优化题直接上 GA → ✅ 规模小优先精确解
3. ❌ 评价题只算 AHP → ✅ 主观 + 客观双轨
4. ❌ 机理题没有微分方程推导 → ✅ 数学公式不能省
5. ❌ 模型太复杂,数据撑不起来 → ✅ 简单模型 + 充分解释更稳

## 案例:2024 国赛 B 题(锂电产能)

题目简化:预测 + 优化 + 评价混合。

- **问题1(机理)**:锂电池放电建模 → 微分方程 + 参数拟合
- **问题2(预测)**:未来产能预测 → ARIMA + XGBoost
- **问题3(优化)**:产能最优配置 → 线性规划 + GA 双轨
- **问题4(评价)**:多种方案排序 → AHP + 熵权 + TOPSIS

每个问题分别走对应决策树,组合成完整方案。
