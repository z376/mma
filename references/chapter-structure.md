# 论文章节结构(v3,2026 Word 模板对齐)

> **单一来源**:任何 mma 文档引用章节命名,都从这里取。其他文档用一句话指向即可。

---

## 11 个 .tex 主文件

```
论文/
├── 0.摘要.tex              ≤900 字,恰好 1 页
├── 1.问题重述.tex          PDF 模板措辞 + \textbf{问题 N:} 每条 ≤2 行
├── 2.问题分析.tex          含 1.1/1.2/1.3/1.4 \subsection + 整体思路图
├── 3.模型假设.tex          itemize,数量 ≈ 问题数
├── 4.符号说明.tex          longtable,列宽比例总和 = 1.04-0.04N
├── 5.模型的建立与求解.tex  4 个 \subsection(问题 1/2/3/4)
├── 6.模型检验.tex          含 6.1/6.2/6.3 \subsection(跨问题)
├── 7.模型优缺点评价.tex    含 7.1/7.2/7.3 \subsection
├── 0.AI声明.tex            放 9.参考文献.tex 之前
├── 9.参考文献.tex          8-15 条,GB/T 7714-2015,AI 工具必须列
└── 10.附录.tex             附录 1 文件列表 / 附录 2 源代码(标注 AI) / 附录 3 其他
```

**8.章已删除**(并入 7.3 改进)。

## 5.x 子节结构(每个问题 5 个子节)

```
5.X.1 数据预处理        仅问题 1 需要(缺失值/异常值/标准化公式 + 结果统计表)
5.X.2 XXX 模型的建立    具体分析 + 9 框 TikZ 流程图 + 算法对比表 + 步骤 1-4 推导
5.X.3 XXX 模型的求解    结果表 + 3-6 张图(系数/重要性/预测 vs 实际) + 5 折 CV
5.X.4 XXX 模型的检验    5 折 CV + 误差 + 灵敏度(±10% ±20%) + 稳健性
5.X.5 XXX 结果的分析    关键发现 + 与对比方法对比 + 总结
```

5.2.x / 5.3.x / 5.4.x 同样 5 个,共 20 个子节文件。

## 2.x 子节结构(问题分析)

```
2.1 问题一的分析
2.2 问题二的分析
2.3 问题三的分析
2.4 问题四的分析(可选)

+ 末尾:"针对以上问题..." + 整体思路图(图 1 问题的总分析,9 框 TikZ)
```

---

## 6.x 子节结构(模型检验,跨问题)

```
6.1 误差分析        5 折交叉验证 + RMSE/MAE/MAPE
6.2 灵敏度分析      核心参数 ±10% ±20% 扰动
6.3 稳健性检验      替换多种算法 + 调整参数区间
```

---

## 7.x 子节结构(模型优缺点评价)

```
7.1 模型的优点    itemize,4-6 条(简洁实用/创新性/准确性/实用性/稳定性)
7.2 模型的缺点    itemize,2-4 条
7.3 模型的改进    1 段自然段落,具体方向
```

## 附录结构(10.附录.tex)

```
附录 1:文件列表(附件说明表)
附录 2:源代码(每段代码后标注 AI 工具:"该部分代码使用 AI 工具:DeepSeek, ...")
附录 3:其他(详细证明/流程图/数据/图表)
+ 支撑材料说明(2026 规定第 11 条)
+ 运行环境(Python/库版本)
```

## 引用规则

- 任何 mma 文档**不要复制**这个表,只写"见 `references/chapter-structure.md`"
- 例外:`examples/README.md` 可以简化为目录树(作为示例入口)
- `references/scripts/auto_verify.py` 内置了 11 个 .tex 文件名清单(机器检查需要),**保持同步**:改此处时同步改 auto_verify.py 里的 `required` 列表
- 写作硬规则(7 条 + 硬性数字)见 `references/writing-rules.md`(并列单一来源)
