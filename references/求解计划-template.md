## 3. 数据预处理流程

> 谁读、谁处理、谁输出 `预处理数据.csv`。

### 3.1 数据加载

| 文件 | 来源 sheet / 表 | 用途 |
|------|----------------|------|
| 【例:附件.xlsx】 | 【男胎检测数据 / 女胎检测数据】 | 原始数据 |
| 【例:附件 2】 | 【】 | 【】 |

### 3.2 清洗步骤

- **缺失值:**【KNN 插补 / 均值填充 / 删除】
- **异常值:**【3σ 准则 / IQR / 箱线图】
- **重复测量:**【取首次达标 / mixedlm / 留全部】
- **日期/分类:**【编码 0/1 / 独热 / 留字符串】

### 3.3 特征工程

- **新衍生:**【例:孕周_数值("11w+6" → 11.857)、BMI 分组、|Z|>3 标记】
- **标准化:**【Z-score / Min-Max / 不标准化(树模型)】
- **最终输出:** `求解/预处理数据.csv`(供问题 1-4 共享)

## 4. 误差分析 + 灵敏度分析计划

> 对应 `建模思路.md` 第 6 段"多模型对比与验证设计"。

### 4.1 误差分析

- **方法:**【5 折 / 10 折分层 CV,RMSE / MAE / MAPE】
- **指标:**【例:RMSE < 5% / MAPE < 10%】

### 4.2 灵敏度分析

- **方法:**【核心参数 ±10% / ±20% 扰动】
- **关注的参数:**【例:BMI 分组阈值 / Y 浓度判据 4% / 树模型 max_depth】

### 4.3 稳健性检验

- **方法:**【替换对比算法 / 调整参数区间 / 不同随机种子】

## 6. 风险与备选

| 风险 | 影响 | 备选方案 |
|------|------|----------|
|【例:pymoo 没装】|多目标优化做不了|用加权求和 + ε-约束替代(本案例做法)|
